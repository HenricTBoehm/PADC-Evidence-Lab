# Ungoverned Transduction — v0.3.1 supplementary research artifacts

**Companion to:** Henric T. Böhm (27 October 2026), *Ungoverned Transduction: When AI-Enabled Effects Outrun Authority*, independent Concept Note v0.3.1 (nine-page PDF). The paper itself is intended for author-controlled distribution, including an Academia.edu paper page; **no Academia.edu publication or peer review is claimed here.**

## Scope and status

This directory provides a deterministic **synthetic** finite-case witness, not an experiment with deployed AI agents. It belongs to the paper's research package and does **not** represent a feature, validation result, release, or interface of the **PADC Evidence Lab** software prototype hosted in this repository.

The eight declared cases differentiate observed effects, end-to-end admissibility, missing evidence, a valid-but-negative-value effect, a correctly blocked attempt, and an explicit authority-promotion witness. A fully specified conventional authorization baseline **also** detects the W1 witness. Nothing here demonstrates PADC's empirical superiority over end-to-end Zero Trust / ABAC / workflow authorization.

The frozen model is intentionally named **v0.2**, even though the associated paper is **v0.3.1**. Paper revisions corrected notation, terminology, temporal interpretation, provenance, and presentation; they did not change model logic or expected case classifications.

## Files

- `UT_v0_2_finite_model.py` — frozen Python source (Python >= 3.9, standard library only).
- `UT_v0_2_finite_cases.csv` — byte-for-byte reference CSV generated by that source (CRLF line endings).
- `UT_v0_3_expected_stdout.txt` — nine invariant console lines, excluding the environment-dependent final `CSV:` path.
- `SHA256SUMS.txt` — SHA-256 manifest for the three frozen artifacts.
- `ACADEMIA_METADATA.md` — draft author-facing upload metadata and distribution boundaries.

## Reproduce

Run from the directory containing these files, using a **scratch directory** so the checked-in CSV is not overwritten:

```sh
scratch="$(mktemp -d)"
cp UT_v0_2_finite_model.py "$scratch/"
python3 "$scratch/UT_v0_2_finite_model.py" > "$scratch/stdout.txt"
cmp "$scratch/UT_v0_2_finite_cases.csv" UT_v0_2_finite_cases.csv
sed '/^CSV: /d' "$scratch/stdout.txt" | cmp - UT_v0_3_expected_stdout.txt
sha256sum -c SHA256SUMS.txt
```

On Windows, run the script in a separate directory and compare the regenerated CSV and the first nine console lines using `filecmp` / `hashlib` from Python's standard library. A full execution prints a final `CSV:` line whose absolute path depends on the environment.

**Expected result:** eight declared case classifications and the statement `PASS: 8 declared synthetic cases, local/global witness, positive control, negative-value case, and strong-baseline blocking check.`

The original model and CSV were previously independently reproduced under CPython 3.12.14 (reported review); they were also run locally under Python 3.13.5. These checks establish only that the encoded cases match their frozen expectations.

## Interpretation

`baseline_decision` is a stipulated **decision-time** authorization verdict. It is not evidence that the effect later occurred or was observable. In O1, `PERMIT` is a counterfactual evaluation of stipulated policy attributes without an actual invocation.

The witness W1 has local permissions `True`, but the global end-to-end guard is `False`: a status is promoted into authority without a sufficient mandate. A competent end-to-end enforcement policy would deny this case. A positive control shows that an admissible effect may still have negative net value. Unknown evidence is `None`/non-evaluable unless a known violation is independently established.

The manuscript is based on the earlier *Pre-Action Differentiation Cascade* v0.4.0 terminology. It does not claim completed alignment with the current *Pre-Action Differentiation and Control* baseline or an authoritative DEA publication master. The complete Shadow-AI paper, literature completeness, human release declarations, and comparative real-world tests remain outside the scope of these artifacts.
